# Diesel Buy Planner

Fuel buy planner and shareable report creator, served at `/diesel-planner/`. Static, no build step. Demo data: City of Columbus public 2026 diesel purchase-order and invoice records for one supplier account. Unofficial prototype, not Cenovus data.

Load your own records through Settings → Load data (same shape as `data.json`). Report downloads are single self-contained HTML files. Nothing leaves the visitor's device and no third-party requests are made.
